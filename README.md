# Prince Rana &mdash; Next-Gen Developer Portfolio

A production-grade, high-performance developer portfolio built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **React Three Fiber**.

Combines Apple-grade minimalism and precision with an atmospheric, cyberpunk-inspired 3D digital universe.

---

## Tech Stack & Architecture

- **Core:** Next.js 14 (App Router), React 18, TypeScript strict mode
- **Styling:** Tailwind CSS with custom dark mode cyberpunk tokens
- **3D Graphics:** Three.js, React Three Fiber, Drei, PostProcessing (adaptive performance profile)
- **Animation:** GSAP, ScrollTrigger, Framer Motion, Lenis (unified ticker synchronization)
- **Testing:** Vitest, React Testing Library, Playwright
- **CI/CD:** GitHub Actions (linting, typechecking, testing, production build verification)

## Getting Started

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/RANAPRINCE06/My-Portfolio.git
cd My-Portfolio
npm install
```

### 2. Environment Configuration
Copy the template and configure your local environment variables:
```bash
cp .env.example .env.local
```

### 3. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
